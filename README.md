E-commerce Return Rate Reduction Analysis

Project Overview

This project analyzes e-commerce product returns to understand why customers return products and how businesses can reduce return rates.

Using Python, SQL, Machine Learning, and Power BI, the project identifies return patterns across product categories, suppliers, regions, and marketing channels.

Project Objectives

- Analyze product return rates.
- Identify products and categories with high returns.
- Compare supplier performance.
- Analyze returns across different regions.
- Understand marketing channel performance.
- Predict product return probability using Machine Learning.
- Create an interactive Power BI dashboard.

Tools & Technologies

- Python: Data cleaning and analysis.
- Pandas & NumPy: Data processing.
- Matplotlib & Seaborn: Data visualization.
- SQL: Business data analysis.
- Machine Learning: Logistic Regression.
- Scikit-learn: Model development and evaluation.
- Power BI: Interactive dashboard.

Dataset Information

- Raw records: 100,070
- Cleaned records: 100,000
- Raw columns: 20
- Cleaned columns: 28
- Products: 2,500
- Suppliers: 30
- Duplicate records removed: 70

The dataset contains order details, product information, customer ratings, delivery details, marketing channels, regions, and return status.

Note: This project uses synthetic data for learning and analysis.
